# AI Academic Report System — Public Prototype

This repository contains the **frontend-only public preview** of AI Academic Report System.

- Main development repository and backend remain private.
- This public repository is intentionally limited to the static browser interface.
- Project metadata and attachments are stored locally in the browser (localStorage / IndexedDB).
- Backend-dependent features (AI provider, research API, document processing, exports, cloud sync and authentication) are not connected in this public preview.
- Do not place personal, confidential, institutional or research data in this prototype.

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to finish deployment. The public URL will be:
   `https://kuealapis.github.io/ai-academic-prototype/`

This prototype is for interface review, not production use.
